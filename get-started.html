Get Started

Each tool installs on its own.

Memory ultimate-memory-stack v4.0.1

Without it:
Agents forget between sessions.
With it:
A memory for your AI agent, kept as plain files in your own project that you can read, edit and keep in git. Hot and cold tiers save context: an index loads in every session, and older notes move to an indexed archive, loaded only when needed.
Limit:
The memory works through written instructions, so recall is not guaranteed. The notes are plain files you can check.

Security agent-shield v0.2.1 alpha

With it:
Commands that match its list of dangerous patterns are blocked, those that match its list of risky ones are put to you, and everything else is left to your assistant's own permission settings.
Limit:
It is a filter, not a sandbox. In Claude Code, the PowerShell tool, file reads, web fetches, notebook edits and other tools are not checked.

Quick Start

Security agent-shield v0.2.1 alpha

Checks shell commands, and where file writes and edits go, before they run, once wired as a hook. In Claude Code it does not check the PowerShell tool, which Claude Code often uses on Windows (not WSL) and always uses there without Git Bash. It is a filter, not a sandbox. It does not stop prompt injection. All known limits

  1. Needs: Python 3.11 or later. Claude Code 2.1.299 or later recommended.

  2. Install One-line installpip install ai-agent-shield==0.2.1

    On macOS and Linux, install agent-shield in a virtual environment outside your project folder, and start Claude Code each time from a terminal where that environment is active. On any system, skip pipx and uv tool for now, and tell your assistant the same: the hooks can't find an install made that way.

    Then point your assistant at INSTALL_AGENT.md in the repo on GitHub, since the PyPI install does not include that file. It wires the guards into Claude Code. After that, commands that match its list of dangerous patterns are blocked, those that match its list of risky ones are put to you, and everything else is left to your assistant's own permission settings.

    The guide's step 2 installs from GitHub main. You already have 0.2.1 from PyPI, so tell your assistant to skip that step.

  3. Install checkecho '{"tool_input":{"file_path":"~/.claude/settings.json"}}' | python -m agent_shield.write_guard

    Then run agent-shield-plugin status. If the hooks were wired with agent-shield-plugin enable, it should say enabled. For project scope, run agent-shield-plugin --project <dir> status. Status does not show that the hooks fire. Run both checks in the terminal you start Claude Code from (bash, zsh, Git Bash or PowerShell; in cmd.exe the first one prints nothing). If the first one fails there, the hooks will likely fail too, and Claude Code may then let actions through unchecked.

  4. First session: restart Claude Code so the hooks load.

  5. Undo: first agent-shield-plugin disable (run it in your own terminal; it asks you to confirm), then check that no agent_shield entries are left in the settings file, then pip uninstall -y ai-agent-shield, then restart Claude Code. For project scope, the first command is agent-shield-plugin --project <dir> disable. The log in ~/.agent-shield/ and the settings backups stay until you delete them.

If a step fails, open an issue.

For OpenClaw the guide uses the library for now; agent-shield's README shows how to wire its before_tool_call adapter yourself, which needs a recent gateway.

What It Adds to Your Computer

Security: the Python package, and two hook entries in ~/.claude/settings.json or in your project's .claude/settings.json (user or project scope: you pick). agent-shield-plugin backs up that file each time it changes it and keeps up to 10 backups. agent-shield keeps a log in ~/.agent-shield/; the install check writes its first entries. If you agree, your assistant may also write an install record such as ~/.claude/agent-shield-manifest.json.

New to AI agents?

AI agents such as Claude Code and OpenClaw read, edit and run things on your computer when you ask, and each session starts without the last one. Memory gives the agent notes it reads every session. Security checks its commands, and which files it edits, before they run (in Claude Code on Windows, not the ones it runs through PowerShell). More tools are planned.
