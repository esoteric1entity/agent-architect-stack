Problems We Solve

  • Agents forget between sessions. The Memory tool gives your agent a persistent vault so context survives restarts and context-window overflows.
  • Skills and tools are an unvetted supply chain. The Security tool includes a check you can run on a skill or plugin folder before you install it.

Data lives in files you own.

The Memory tool stores everything as plain Markdown + JSON in a vault you can open in Obsidian, grep, version-control, and back up with cp -r.

Who Does What
  • Yours: your harness and agents. Your harness and main agent start and coordinate any helpers; the stack does not.
  • Security (agent-shield, v0.2.1 alpha) sits in the path. It checks shell commands, and where file writes and edits go, before they run, once wired as a hook.
  • In Claude Code, the PowerShell tool, file reads, web fetches, notebook edits and other tools are not checked.
  • Memory (Ultimate Memory Stack v4.0.1, UMS for short) sits beside the path: plain notes in your project folder.
  • More tools planned.
