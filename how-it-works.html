Known Limits

Memory

  • The memory works through written instructions, so recall is not guaranteed. The notes are plain files you can check.
  • Optional add-ons set up third-party tools, and some have known problems in the current release.

The Premise

Purpose

To give AI agents a stable, inspectable, installable infrastructure layer. The Agent Architect Stack is a set of peer-sibling tools an agent harness can install to gain persistent memory, a defensive runtime, and (over time) more.

  • Agent projects are monolithic or scattered. The umbrella model is neither. Each tool is a complete product; the umbrella is a discovery surface, not a runtime dependency.
  • The Security tool's architecture spans 8 layers; the current release ships six of them: Layers 1, 2, 3, 4, 6, and 7 (skill vetting, input sanitization, structured-output enforcement, runtime hooks, audit logging, and configuration).
